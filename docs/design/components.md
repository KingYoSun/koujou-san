# 部品

[入口](../../DESIGN.md) / [基礎](foundations.md) / [パターン](patterns.md) / [見本](examples/ui-patterns.html)

原本からは罫線による区切り、静かな面、小さな角丸を継承する。フォームと以下の状態表はUI向けの追加規則である。適用対象はこの表の七種に閉じる。

| 部品 | 構造と通常状態 | hover・focus-visible | 選択・無効・処理中 |
| --- | --- | --- | --- |
| ボタン | 日本語の動詞＋対象。主操作はgreen、補助は面＋濃い境界 | 主操作はgreen2、補助はwash。3pxの外枠を残す | 選択はトグルに限り `aria-pressed`。無効は `disabled` と理由、処理中は「取得中」などの文字＋ `aria-busy`。処理中を選択色にしない |
| 入力 | 常時見えるlabel、補足、入力欄。placeholderをlabelの代わりにしない | 濃い境界を保ち、focusで外枠 | 無効は理由を併記。誤りは `aria-invalid` と `aria-describedby` の修正説明。処理中も値を消さない。通常入力に選択状態は設けない |
| タブ | 同一作業内の表示切替。`tablist`／`tab`／`tabpanel` を対応 | hoverはwash、focus枠は選択とは独立 | 選択はgreen／white＋ `aria-selected`、非選択の `tabindex=-1`。左右・Home・Endで移動、Tabで内容へ。無効タブは移動対象から外す。処理中はパネル内に示す |
| バッジ | 記号＋短い状態名。通常は中立 | 非操作なのでhover・focusを付けない | 選択・無効・処理中の操作状態を付けない。「取得中」など対象の状態を文字で示す。クリック可能なフィルターはボタンにする |
| 通知 | 対象、理由、次に可能な操作。文字＋記号＋必要な色 | 通知そのものにhover・focusを付けず、内側の操作だけ付ける | 空／失敗／不完全／競合は下表。新しい結果の短い通知に `role=status`、急ぐ入力エラーに `role=alert`。静的な例を読み上げ続けない |
| パネル | 見出し、内容、必要な補足と操作。面と罫線で囲う | 面自体は操作にしない | 選択・無効は内側の対象へ付ける。取得中は見出しを保って本文に明示。失敗・空は通知と組み合わせる |
| 一覧・表 | 行見出し、列見出し、状態、版、由来。罫線と余白で比較 | 操作のある行だけhoverを付け、内部リンク・入力へfocus | 選択はcheckboxとラベル、無効は行内の理由。ページ取得中は既取得行を残し「次のページを取得中」。表全体の並べ替えを完了と見せない |

非操作の面にクリックを連想させるhover・手のカーソルを付けない。無効を薄さだけで説明しない。busy表示や無効化は見本の状態表現であり、製品の再試行・排他契約を追加しない。

| 通知の意味 | 表示例 | 維持する情報 |
| --- | --- | --- |
| 空 | 「一致する候補がありません。検索条件を変更してください」 | 空の対象・条件。Workspace全体のContextが0件とは言わない |
| 失敗 | 「次のページを取得できませんでした」 | 取得済みの内容と再試行対象 |
| 不完全 | 「一部の結果は未取得です。選択案は未採用です」 | 欠けた範囲。未取得を0件・費用0に変えない |
| 競合 | 「元版が変わりました。変更案は保留中です」 | 元版、現在版、変更案、手動固定 |

## 操作と言葉

「定義を保存」「Context選択を依頼」「Runの開始を依頼」のように結果を明示する。定義保存、クライアントLLM操作、Run実行を一つの「実行」にまとめない。見本のボタンは表示の切替かページ内通知だけで、共有状態を変更しない。

Runの「実行中／質問待ち／終了」と、検品の「合格／不合格／判断不能」は別の項目に置く。切断・未同期・未実行は失敗・完了に置換しない。状態色の共用によって意味が等しいように見せない。

アイコンを付ける場合も操作名を残す。表の横スクロール領域には名前とキーボードの入口を付ける。focus枠を切らず、タブ切替の後も候補→選択条件→注入プレビューの読み順を保つ。
