## 出典

視覚表現の原本は2026-10-16作成の[企画HTML](references/koujou-san-project-proposal.html)。[Issue #47の参照コメント](https://github.com/KingYoSun/koujou-san/issues/47#issuecomment-6211837641)にあるHTMLコードブロックを、2026-10-19にUTF-8・BOMなしで取得した。74,390 bytes、SHA-256は `42b00206882ff7042e2ac8daf4a088c0781faa044f761ac91e216b0300548ad2`。末尾改行を追加せず、内容を変更しない。

以下では「原本」を抽出値、「UI調整」を操作画面と見本に使う値として区別する。状態色とフォーム表現は原本にない追加の視覚規則であり、この見本の範囲で定める。本番への適用は別の作業で行う。原本にあるManifestの説明など、過去の企画文章は現行の製品仕様を置き換えない。

| `--paper` | `#f6f5ef` | 画面の地 |
| `--white` | `#fffefa` | 入力・確認する面 |
| `--ink` | `#1c332e` | 主文 |
| `--muted` | `#596862` | 補足文 |
| `--line` | `#d5dbd0` | 装飾的な区切り |
| `--green` | `#183b34` | 主操作、見出し、重点の面 |
| `--green2` | `#285348` | 深緑の補助色 |
| `--lime` | `#deedaa` | 選択・重点の面。文字は深緑 |
| `--wash` | `#e9eee0` | 補助面 |
| `--orange` | `#ba482c` | 注目点、注記の線 |

用途別の名前は[実装対応表](implementation.md#既存cssへの対応)を使う。原本の `--muted` は文字色だが、shadcnの同名変数は面の色なので、名前だけで置換しない。

### UI調整と状態色

| 用途別の組合せ | 前景 / 背景 | 理由 |
| --- | --- | --- |
| 本文 | ink / paper、white、wash、peach、lime | 暗い文字で読む |
| 補足 | muted / paper、white、wash | 補足も通常文字の読みやすさを保つ |
| 主操作 | white / green、hoverはwhite / green2 | 選択と操作を同じ強さにしない |
| 選択 | green / lime | チェック・選択ラベルも付ける |
| 成功 | green2 / wash | 「合格」「同期済み」など対象を明記 |
| 注意 | `#81411f` / peach | 赤茶を暗くし、小さな状態文字を読みやすくする |
| 失敗 | `#a73629` / `#fbebe5` | 「不合格」「取得失敗」など何が失敗したかを明記 |
| 中立・未知 | ink / wash | 「判断不能」「未取得」は失敗色にしない |
| 入力の境界 | `#77877e` / white | 薄いlineは操作境界の識別には使わない |
| フォーカス | green / paper、white、wash | 3pxの外枠＋3pxの間隔。深緑の面ではlimeへ反転 |

ブランド色から成功・注意・失敗を推測させず、状態ラベルと記号を併用する。通常文字は4.5:1以上、大きな文字と識別に必要な操作境界・フォーカスは3:1以上を確認する。lineは装飾用で、状態や入力欄の唯一の境界にしない。実測値は[検証記録](../progress/2026-10-19-issue-47-evidence.md)に置く。

## 書体と文字階層

原本の本文は15px／行間1.85。見出しは700、行間1.45、字間−0.035em。h1は38〜66px、h2は28〜42px、h3は22px、h4は17px。企画資料の主題を強く見せる寸法であり、そのまま操作画面の見出しにしない。

```css
/* 原本のローカル書体。フォントの配信・インストールは要求しない */
--sans: "Hiragino Kaku Gothic ProN", "Yu Gothic", YuGothic,
  "Noto Sans JP", Meiryo, system-ui, sans-serif;
--mono: ui-monospace, "SFMono-Regular", Consolas, "Liberation Mono", monospace;
```

WindowsはYu Gothic／Meiryo、macOSはHiragino、Linuxはインストール済みNoto Sans JPまたはsystem-uiへフォールバックする。OS間の字幅差を許容し、文字数による固定幅・固定高を避ける。対応OSの追加を意味しない。

| UI調整 | サイズ / 行間 | 用途 |
| --- | --- | --- |
| ページ見出し | 28px / 1.4、狭い幅では24px | 現在の作業 |
| 節見出し | 22px / 1.5 | 作業の区切り |
| 小見出し | 17px / 1.5 | 面の目的 |
| 本文・操作 | 16px / 1.65 | 日本語、入力、ボタン |
| 補足・短いメタ情報 | 13px / 1.65 | ID、モデル、版、数量、由来 |

原本にある9〜11pxのメタ情報は操作画面では使わない。等幅は識別子・数値など短い情報に限り、長い日本語説明を等幅にしない。数値の比較は右揃えと `tabular-nums` を使う。URLや長いIDは折り返せるようにする。

## 余白と面

原本は1pxの罫線、タグの3px角丸、面の直角、重点ノードの `5px 5px 0 #0e3027` の硬い影を使う。節は上下90px、見出しと本文は42px、本文の左の番号列は150px。UI調整では作業密度に合わせ、次の値を使う。

| 項目 | UI調整 |
| --- | --- |
| 余白の段階 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px |
| 本文と補足、同じ操作群 | 8px、群の間は16px |
| 行 | 上下12px、左右16pxを起点に文字量で伸ばす |
| パネル | 内側24px、狭い幅は16px。階層ごとにカードを重ねない |
| 区切り | 1px line。節の始まりだけ2px greenを使える |
| 角丸 | 操作・入力・バッジ3px、面0px |
| 影 | 原則なし。重点の見本だけ `3px 3px 0 #183b34` |

## 幅と読み順

原本は最大1160px、1600px以上では1250px、左右合計96pxの余白。580／800／1100／1600pxで構成を切り替える。これは資料の参照値で、製品全体の固定ブレークポイントではない。

見本は最大1160px、左右24px（580px以下は16px）。800pxより広ければ候補とプレビューを二ペイン、以下は候補→プレビューのDOM順で一列にする。最小幅を固定しない。表は列見出しを保ち、必要な横スクロールを表の領域に限定する。ページ全体を横へ送らせない。

検索・フィルター・ページ継続で候補を取得し、選択した版のプレビューを別に確認する。画面内の少数行は取得ページの抜粋であり、全件取得や全件DOM化を要求しない。広い画面でも余白を埋めるためにカードを増やさない。

動きは必要なフィードバックだけに使い、`prefers-reduced-motion: reduce` では移動・滑らかなスクロールを止める。見本はアニメーションを使わない。200%拡大でもDOMの読み順と全操作を保つ。印刷規則は原本と見本だけに適用し、状態・版・由来・未取得を紙面から落とさない。
