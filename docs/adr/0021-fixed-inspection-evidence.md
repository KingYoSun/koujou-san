## 共通Runへの接続

InspectionRunとHumanReviewRunは編集可能な共通Run定義を使う。検品専用の実行エンジンは作らない。検品定義の保存、固定版の採用、実行依頼を分け、対象成果物、条件、Context選択、必要な分離、元のRunと差分の根拠を版付きで保存する。初見検品は`selection.mode=none`を明示する。製品哲学や実装の会話・自己評価は自動で追加しない。

開始時に固定定義からManifestと共通Run.inputを作る。実行依頼の意図を先に保存し、安定した操作IDでRun作成と割当を続ける。既存のRunnerが端末の設定・認証とRunごとのworktree/branchを使う。共有記録にはprogramの実path、CLIの認証、未commitファイルを写さない。割当と起動前には現在の閲覧・実行許可、採用基準、接続能力を再確認する。

## 分離の意味と実CLI調査

会話、作業場所、読み書き権限、外部接続、基準、Contextをそれぞれ未確認・宣言・ログで確認・環境で強制へ分ける。接続の能力文字列だけでは宣言を超えない。機器の観測記録を明示的に参照した場合は、そのログで確認した範囲を記録する。これはログ内容の独立した真偽証明ではない。

サーバーが強制する基準とContextの保証は、基準版とManifestによる注入内容の固定である。CLIがOSから読める全ファイル、資格情報、記憶を隔離した保証へ拡張しない。必須条件を満たせない接続は開始しない。ログや未確認の能力を、強制済みへ格上げしない。

WindowsのCodex CLI `0.162.1`とClaude Code `2.1.300`を、リポジトリ外の新しい一時ディレクトリから固定promptで実行した。Codexは`exec --ephemeral --ignore-user-config --sandbox read-only`、Claudeはprintモードの`--safe-mode --restricted --no-session-persistence --tools ""`を使い、両方が終了0で同じ合成マーカーを返した。CodexのJSONLには作業ツール呼出しがなく、Claudeの原結果にもエラー・許可拒否はなかった。通常の既存認証を使い、認証ファイルの複製・保護設定の解除は行っていない。

Codexのephemeralはセッション保存を抑止する設定であり、全メモリ・資格情報の隔離の証拠にはしない。[公式CLI資料](https://learn.chatgpt.com/docs/developer-commands?surface=cli)とインストール済みのhelpを参照した。Claudeのsafe modeはカスタマイズを読み込まず、restrictedは組込みツールや設定を制限するが、管理ポリシーと通常の認証は別に残る。[公式CLI資料](https://code.claude.com/docs/en/cli-reference)とhelpを照合した。CLIの版とこれらの設定を記録した範囲で方式調査を終了する。OS全体の読取り禁止、別利用者の認証との隔離、モデル側の記憶消去は未確認である。

## 原出力と判定

原ログと共通Runの原レポートを保持し、終了コード、形式、内容の受入れを分ける。`inspection-report-v1`は固定検品版、Manifest digest、全条件の判定、実行の有無、証拠の固定参照、未確認を持つ。自然文を推測でJSONへ置き換えない。宣言したトップレベルの判定field名だけを決定的に読み替え、元のレポートは保持する。

共通Runの終了処理で条件と証拠を照合し、工程が使う受入判定にも反映する。終了0のFAIL、形式不正、条件欠落、未実行、根拠不足をPASSにしない。差分再利用には以前の判定、変更範囲、影響確認、固定証拠を必要とし、不足はINCONCLUSIVEとして残す。推奨経路を工程や権限の変更として実行しない。

## 過去の判定と現在の有効性

採用対象・条件・必要な入力が変わると、以前の検品を現在の対象へ適用する状態はStaleになる。旧Run.input/outputと当時の判定を変更せず、新しいRunと必要なら`previous`で関連付ける。定義の下書きを保存するだけでは採用基準を変えない。

機器の観測、人の確認、AIコメント、実装者の申告を分け、対立する判定を並べて取得できる。人の例外判断は、対象Runを編集できるメンバーが理由・条件・未確認とともに保存する別の記録である。元のFAIL/INCONCLUSIVEや実行権限は変更しない。

外部証拠の当時の固定参照と、現在の利用可否を分けて表示する。所在失効は当時の判定の書換えではない。記録は承認済みの無期限保持とし、成果物全量の中央コピーや新しい期限は導入しない。定義・証拠の一覧は索引付きメタデータ、選択対象の履歴は固定範囲のページとして取得し、Context全件や全原出力を走査しない。
