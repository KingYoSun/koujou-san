# 三ペインの共通シェル・ノード型工程表示・Slack風Projectチャット

直接の依頼から始める。[計画指針](../../PLANS.md)と[Issueから実装する手順](../runbooks/issue-lifecycle.md)に従う。

## 目的と範囲

- 依頼: 共通UIを「左サイドバー／中央にノードベースの工程表示／右に選択ノードの詳細」の三ペインにする。ProjectチャットはSlack風にして中央へ置き、工程表示中も右下のpopoverから同じチャットを呼び出せるようにする。
- 目的: 画面間の移動、工程の構造把握、選択ノードの編集・判断、Projectの相談を同じ画面構成で行えるようにする。
- 対象の利用場面: Workspaceへ参加済みの利用者がWeb／Tauriの共通UIで、工程定義の編集、工程実行の確認・判断、Projectチャットの閲覧・保存・AI相談を行う。
- 対象外: API・保存データ・wire契約の変更。工程実行エンジンの状態や遷移の追加。ノードのドラッグ配置・自由レイアウトの保存。新しいUIフレームワーク・テーマパッケージの導入。全画面ダークテーマ。
- 基準commit: `ac3a72d`（main）。作業開始時の変更なし。
- 確認の区分と理由: B。操作・表示の変更で、保存・認証・実行の経路は変えない。
