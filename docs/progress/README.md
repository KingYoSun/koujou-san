# 現在の状態と作業記録

実装済みの範囲、検証結果、未確認事項を記録する。設計上の提案は[設計書](../../koujou-san-design-doc.md)と[ADR](../adr/README.md)へ置く。

- `current-state.md` は現在の到達点、残作業、次に実装できる範囲を示す。
- `YYYY-MM-DD-<issue番号または作業名>-<slug>.md` は、その作業で行った変更と証跡を示す。

個別記録には、依頼と基準commit、受入条件ごとの結果、実行したコマンドと結果、未実行・失敗の理由、残作業を記す。直接の依頼ではIssue番号を作る必要はない。

現在の判定を複数ファイルで独立管理せず、個別の証跡から参照する。後で状態が変わっても、過去の記録は当時の結果として残す。環境構築や未接続の基盤を、製品の段階Aや初期リリースの完成と数えない。
