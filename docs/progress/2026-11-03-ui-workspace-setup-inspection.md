## 指摘と修正

metadataだけの接続保存で、現在のVersionがmutationのdigestへ入り、同じ要求を再送すると競合扱いになる回帰を指摘した。`704503f`でdigestから現在Versionを除き、同じ要求の再送試験を追加した。

OAuthアプリ設定全体がWorkspace管理者の条件内にあり、server adminでもWorkspaceがeditor/viewerなら登録UIを開けない未達を指摘した。`399ad82`で全体設定とWorkspace操作の条件を分け、実DOM・静的描画試験を追加した。再検品で両指摘の解消を確認した。

## 判定

`399ad82`のAC-U1〜U5とINVAR-U1〜U3には残るblockerなし。検品担当は試験を再実行せず、ソースと提示された所有試験結果を照合した。AC-U6、実幅1440px・1024px、Desktopの実ブラウザ往復は未確認のままである。

私有配備手順も固定checksumで別途確認した。元のmigrationの不変、非公開backup、追加移行、設定・identity保持、外部サービスを再起動しないこと、OAuthや割当を自動作成しない境界にblockerはない。接続済みネットワークからのHTTP 200は疎通の証拠であり、未認証の外部利用者に対するAccess gateの証拠にはしない。
